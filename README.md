>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и попадает в карантин. В таком случае детект обычно называется `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение; при сомнениях рекомендуется отключить детектирование PUA.

## ⚙️ Установка и запуск

1. Сначала включите безопасный DNS — Secure DNS.
    * В Chrome активируйте "Использовать безопасный DNS" и укажите провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Пользователи Windows 11 могут включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Откройте [страницу последнего релиза](https://github.com/lunardataemancipate/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar.

3. В свойствах загруженного архива установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не обязателен.

4. Извлеките файлы в путь без кириллицы и специальных символов.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить запуск вместе с системой, выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️ Назначение основных файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включён ли режим.
  - **`IPSet Filter`** — изменить обработку сервисов из `ipset-all.txt`.  
  Опция пригодится при диагностике ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается текущее состояние:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется принадлежность IP к списку
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения
  - **`Run Tests`** — проверить стратегии:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️ Частые вопросы и решения

### После запуска `general*` не видно никаких изменений

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/522).

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку от имени администратора.
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Веб-версия Telegram не подключается
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - В появившейся папке откройте `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированный текст в конец `hosts` либо замените прежние аналогичные строки.
  - Сохраните изменения и проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Результат не гарантируется. При отсутствии эффекта используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/lunardataemancipate/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Вариант, который некоторое время обходил блокировку, может перестать работать после его обнаружения.
> Здесь собрано много стратегий. Если ни одна не помогает, создайте новую на основе существующей и измените её параметры.
> Описание параметров находится [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` → `Run Diagnostics` не показывает ошибок.

- Проверьте, добавлен ли нужный ресурс в списки доменов или IP-адресов.

- Испытайте другие варианты (**`ALT`**, **`FAKE`** и прочие).

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация — в [#765](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие данные.
- Перезагрузите устройство.
- Выполните `service.bat` → `Remove Services`.
- Откройте `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите старую папку zapret.
- Скачайте свежую версию на [странице релизов](https://github.com/lunardataemancipate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой мыши на архив, откройте свойства и, если доступна кнопка разблокировки, установите флажок, нажмите применить и затем OK.
- Распакуйте архив в новую папку в корне диска, не используя пробелы, спецсимволы и кириллицу.
- Переберите разные скрипты `general`. После каждого запуска проверяйте нужные интернет-ресурсы: если они не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал против них активно бороться.
- Если прежняя стратегия перестала помогать, попробуйте остальные.
- См. также [#251](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, изменилось ли поведение приложения Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ею.
- Если браузер тоже не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/252).

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/lunardataemancipate/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующий порядок:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить доступ ко многим сайтам. Не оставляйте его включённым постоянно. Вместо этого выясните IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

- Создайте обращение [здесь](https://github.com/lunardataemancipate/zapret-discord-youtube/issues).

## 🗒️ Добавление других адресов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например если IP их сети есть в `ipset-all.txt`, но сам домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
