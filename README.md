## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив со [страницы последнего релиза](https://github.com/lunardataemancipate/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — настроить обработку сервисов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках указано состояние:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — адрес проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe (обход). Если его нет, обратитесь к [#522](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - От имени администратора откройте текстовым редактором файл `hosts` в созданной папке.
  - Вставьте скопированный текст в конец файла `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните изменения и снова проверьте подключение. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/lunardataemancipate/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работоспособность.**
> Вариант, который некоторое время успешно обходил блокировку, позднее может перестать работать после его обнаружения.
> В репозитории собрано много стратегий. Если ни одна не подходит, создайте новую на основе существующей, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` → `Run Diagnostics` проверьте отсутствие ошибок.
- Удостоверьтесь, что адрес ресурса присутствует в списке доменов или IP.
- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/lunardataemancipate/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; исправьте ошибки и в конце выберите Y.
- Удалите текущую папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/lunardataemancipate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если доступен флажок разблокировки, установите его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новую папку в корне диска, не используя пробелы, спецсимволы и кириллицу.
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию.
- После выбора рабочей стратегии включите автозапуск через `service.bat` → `Install Service`.

### Не работает игра/приложение с включённым запретом

- В `service.bat` убедитесь, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Используйте инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Узнайте имя службы в командной строке Windows, открыв Win+R и введя `cmd`:

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите службу, подставив полученное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если прежний вариант перестал работать, переберите остальные стратегии.
- Дополнительно см. [#251](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте, помогла ли очистка в приложении Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если браузерная версия также недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/lunardataemancipate/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если результата нет, создайте обсуждение в [Discussions](https://github.com/lunardataemancipate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/lunardataemancipate/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
